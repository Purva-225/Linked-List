## 🚀 About This Repository

This repository documents my journey of learning and completing the **Linked List topic in Data Structures and Algorithms (DSA)** using C++.

I started with the fundamentals, such as creating nodes, traversing a linked list, converting arrays into linked lists, and performing insertion and deletion operations. Gradually, I moved toward solving complex problems involving pointers, reversing linked lists, cycle detection, merging, sorting, and other important patterns.

Practicing problems across platforms like **LeetCode and GeeksforGeeks**, along with fundamental implementation questions, helped me strengthen my understanding of pointers, node connections, and efficient problem-solving.

🎯 **Goal:** Build strong DSA fundamentals, understand the logic behind every solution, and improve time and space complexity analysis.

## 🧠 What I Learned

### 1. Linked List Fundamentals
- Understanding nodes, data, and pointers.
- Creating and traversing a linked list.
- Calculating the length of a linked list.
- Searching for an element.
- Converting an array into a linked list.

### 2. Insertion and Deletion
- Insertion at the beginning and end.
- Insertion at a given position.
- Deleting the head, tail, middle, or a specific node.
- Handling edge cases such as empty lists and single-node lists.

### 3. Doubly Linked Lists
- Understanding `prev` and `next` pointers.
- Inserting and deleting nodes at different positions.
- Deleting all occurrences of a key.
- Removing duplicates from a sorted doubly linked list.
- Finding pairs with a given sum.

### 4. Reversal and Rearrangement
- Reversing a linked list.
- Finding the middle node using the slow and fast pointer technique.
- Checking whether a linked list is a palindrome.
- Rotating a linked list.
- Rearranging nodes into odd and even positions.
- Sorting a linked list containing 0s, 1s, and 2s.

### 5. Cycle and Pointer Problems
- Detecting a cycle using Floyd's Tortoise and Hare algorithm.
- Finding the starting node of a cycle.
- Calculating the length of a loop.
- Finding the intersection of two linked lists.
- Removing the N-th node from the end.
- Deleting the middle node.

### 6. Advanced Linked List Problems
- Adding two numbers represented by linked lists.
- Adding one to a number represented by a linked list.
- Merging two sorted linked lists.
- Merging K sorted linked lists.
- Sorting a linked list using merge sort.
- Copying a linked list with random pointers.
- Reversing nodes in groups of K.

## ⚙️ Important Techniques I Practiced

- **Two-pointer technique:** Using slow and fast pointers to find the middle or detect cycles.
- **Dummy node:** Simplifying insertion, deletion, and merging operations.
- **In-place reversal:** Changing pointer connections without creating an entirely new list.
- **Pointer switching:** Finding intersections efficiently.
- **Recursion:** Solving problems by breaking them into smaller subproblems.
- **Merge sort:** Sorting linked lists efficiently.
- **Edge-case analysis:** Handling empty lists, single nodes, and boundary positions.

## ⏱️ Complexity Analysis

Understanding complexity is an important part of my practice.

| Operation | Typical Time Complexity |
|---|---|
| Traversal | \(O(n)\) |
| Searching | \(O(n)\) |
| Insert at head | \(O(1)\) |
| Delete head | \(O(1)\) |
| Insert at tail | \(O(n)\) without a tail pointer |
| Find middle using slow/fast pointers | \(O(n)\) |
| Reverse a singly linked list | \(O(n)\) |
| Detect a cycle using Floyd's algorithm | \(O(n)\) |

Actual complexity can vary depending on the implementation and whether additional pointers are maintained.

## 🔥 Key Takeaway

Linked Lists taught me to think carefully about **pointers, memory connections, and how changing one reference can affect an entire data structure**.

Problems such as Linked List Cycle helped me understand the Tortoise and Hare technique, while reversal, palindrome, and rotation problems improved my ability to trace pointer changes step by step.

Completing this topic has strengthened my DSA foundation and prepared me to move forward to more challenging problems.
